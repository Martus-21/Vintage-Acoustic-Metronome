🎵 Vintage Acoustic Metronome

A visually rich, interactive JavaScript metronome inspired by classic mechanical designs.
This app combines smooth animations, customizable sound, and musical timing controls to create a realistic practice tool for musicians.

📸 Screenshot




✨ Features
🎚️ Adjustable tempo (40–320 BPM)
🎼 Multiple time signatures (2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 9/8, 12/8)
🔊 Volume control
🔔 Multiple sound options (Click, Wood, Beep)
🎨 Theme switching (Dark, Light, Ocean)
🎵 Italian tempo presets (Grave → Prestissimo)
🕰️ Animated pendulum using GSAP
🔊 Audio playback powered by Howler.js
👆 Clickable metronome to start/stop
🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla)
GSAP (animations)
Howler.js (audio)
